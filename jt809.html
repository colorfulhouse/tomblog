JT809 协议

JT809 道路运输车辆卫星定位系统平台数据交换

JTT 809-2011 / 2019 标准详解

协议概述

JT809 是中华人民共和国交通运输行业标准，规定了道路运输车辆卫星定位系统中，上下级平台之间进行数据交换的技术要求、消息格式和传输协议。

标准版本

  • JTT 809-2011 - 初始版本
  • JTT 809-2019 - 修订版本（新增时间戳字段）

应用场景

  • 上下级监管平台数据交换
  • 企业平台与政府监管平台对接
  • 跨区域平台互联互通

数据包结构

基本结构

JT809Package
头标识 5B
数据头 4-10 字节
数据体 可变长度
CRC校验 2 字节
尾标识 5D
EndFlag: 5D | BeginFlag: 5B

数据头字段

字段名 长度 说明
MsgLength 4 字节 数据头 + 数据体长度
MsgSN 4 字节 报文序列号（唯一标识）
BusinessType 2 字节 业务数据类型（消息 ID）
MsgGNSSCENTERID 4 字节 下级平台接入码（上级分配的唯一标识码）
Version 3 字节 协议版本号标识（如 01 00 00 = 2011版）
EncryptFlag 1 字节 报文加密标识位
EncryptKey 4 字节 数据加密密钥
Time 5 字节 发送消息的系统时间（2019版新增）

数据转义规则

为确保 TCP 消息边界的正确识别，JT809 协议对数据内容进行了转义处理：

原字符 转义后 反转义
0x5B (起始标记) 0x5A 0x01 0x5A 0x01 → 0x5B
0x5A (转义标记) 0x5A 0x02 0x5A 0x02 → 0x5A
0x5D (结束标记) 0x5E 0x01 0x5E 0x01 → 0x5D
0x5E (扩展标记) 0x5E 0x02 0x5E 0x02 → 0x5E

消息类型分类

链路管理类

  • 0x1001 - 主链路登录请求消息
  • 0x1002 - 主链路登录应答消息
  • 0x1003 - 主链路注销请求消息
  • 0x9001 - 从链路连接请求消息
  • 0x9002 - 从链路连接应答消息

信息统计类

  • 0x9101 - 接收定位信息数量通知消息
  • 0x9102 - 平台链路连接情况上报请求消息
  • 0x9103 - 下发平台间消息序列号通知消息

车辆动态信息交换

  • 0x1202 - 实时上传车辆定位信息
  • 0x9202 - 交换车辆定位信息消息
  • 0x1203 - 车辆定位信息自动补报
  • 0x1200 - 主链路动态信息交换消息

车辆报警信息交互

  • 0x1400 - 主链路报警信息交互消息
  • 0x9400 - 从链路报警信息交互消息
  • 0x9401 - 报警督办请求消息
  • 0x9402 - 报警预警消息

平台间信息交互

  • 0x1300 - 主链路平台间信息交互消息
  • 0x9300 - 从链路平台间信息交互消息
  • 0x1301 - 平台查岗应答消息
  • 0x9301 - 平台查岗请求消息

车辆监管类

  • 0x1500 - 主链路车辆监管消息
  • 0x9500 - 从链路车辆监管消息
  • 0x9501 - 车辆单向监听请求
  • 0x9502 - 车辆拍照请求

C# 实现示例

1. 使用 NuGet 包

# 安装 NuGet 包
Install-Package JT809
# 或安装支持音视频的扩展包
Install-Package JT809.Protocol.Extensions.JT1078

2. 组包（序列化）

// 创建 JT809 数据包
JT809Package jT809Package = new JT809Package();

// 设置数据头
jT809Package.Header = new JT809Header
{
    MsgSN = 1666,                           // 报文序列号
    EncryptKey = 9999,                      // 加密密钥
    EncryptFlag = JT809Header_Encrypt.None, // 不加密
    Version = new JT809Header_Version(1, 0, 0), // 2011版
    BusinessType = JT809BusinessType.从链路报警信息交互消息.ToUInt16Value(),
    MsgGNSSCENTERID = 20180920,            // 下级平台接入码
};

// 设置数据体
JT809_0x9400 bodies = new JT809_0x9400
{
    VehicleNo = "粤A12345",                  // 车牌号
    VehicleColor = JT809VehicleColorType.黄色, // 车辆颜色
    SubBusinessType = JT809SubBusinessType.报警督办请求消息.ToUInt16Value(),
};

// 设置子数据体
JT809_0x9400_0x9401 alertData = new JT809_0x9400_0x9401
{
    WarnSrc = JT809WarnSrc.车载终端,          // 报警来源
    WarnType = JT809WarnType.疲劳驾驶报警.ToUInt16Value(),
    WarnTime = DateTime.Parse("2018-09-27 10:24:00"),
    SupervisionID = "123FFAA1",
    SupervisionEndTime = DateTime.Parse("2018-09-27 11:24:00"),
    SupervisionLevel = 3,
    Supervisor = "smallchi",
    SupervisorTel = "12345678901",
    SupervisorEmail = "123456@qq.com"
};

bodies.SubBodies = alertData;
jT809Package.Bodies = bodies;

// 序列化为字节数组
byte[] data = JT809Serializer.Serialize(jT809Package);
string hex = data.ToHexString();
// 输出: 5B 00 00 00 92 00 00 06 82 94 00 01 33 EF B8 ...

3. 解包（反序列化）

// 将十六进制字符串转为字节数组
var bytes = "5B 00 00 00 92 00 00 06 82 94 00 ... 5D".ToHexBytes();

// 反序列化
JT809Package jT809Package = JT809Serializer.Deserialize(bytes);

// 解析数据头
uint msgLength = jT809Package.Header.MsgLength;     // 146
uint msgSN = jT809Package.Header.MsgSN;             // 1666
JT809BusinessType businessType = (JT809BusinessType)jT809Package.Header.BusinessType;

// 解析数据体
JT809_0x9400 alertBody = (JT809_0x9400)jT809Package.Bodies;
string vehicleNo = alertBody.VehicleNo;              // "粤A12345"

// 解析子数据体
JT809_0x9400_0x9401 alertData = (JT809_0x9400_0x9401)alertBody.SubBodies;
string supervisionID = alertData.SupervisionID;      // "123FFAA1"
DateTime warnTime = alertData.WarnTime;              // 2018-09-27 10:24:00

4. 配置多个版本

// 同时使用 2011 和 2019 版本
IServiceCollection serviceDescriptors = new ServiceCollection();
serviceDescriptors.AddJT809Configure(new JT809_2011_Config());
serviceDescriptors.AddJT809Configure(new JT809_2019_Config());

// 获取对应的序列化器
JT809Serializer serializer2011 = ServiceProvider.GetRequiredService<JT809_2011_Config>().GetSerializer();
JT809Serializer serializer2019 = ServiceProvider.GetRequiredService<JT809_2019_Config>().GetSerializer();

public class JT809_2019_Config : JT809GlobalConfigBase
{
    public override string ConfigId => "JT809_2019";
    public JT809_2019_Config()
    {
        Version = JT809Version.JTT2019;  // 使用 2019 版本
    }
}
