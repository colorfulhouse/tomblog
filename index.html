JT809 平台数据交换协议

道路运输车辆卫星定位系统 | JTT 809-2011/2019

项目简介

JT809 协议实现了道路运输车辆卫星定位系统上下级平台之间的数据交换，支持主链路和从链路的双链路通信机制。

交通运输监管平台

技术栈：Java Spring Boot + Vue.js

  • 实现 JT809-2011/2019 协议上下级平台数据交换
  • 支持主链路和从链路的双链路通信机制
  • 完成车辆定位信息实时交换（0x1202 / 0x9202）
  • 实现报警信息交互（疲劳驾驶、超速等）
  • 支持音视频实时传输（基于 JT1078 扩展）

安全监测网关

技术栈：Go + MySQL

  • 设计高并发 TCP 服务端，支持数千路 GNSS 终端连接
  • 实现 JT809 协议解析与转发网关
  • 完成车辆定位数据实时采集与存储
  • 实现消息补传与重发机制，确保数据完整性

技术栈

C# Java Go Spring Boot Vue.js MySQL Redis TCP/IP JT809 JT1078
